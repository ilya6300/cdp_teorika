1. ## трекинг посетителя

трекинг cdp должно отслеживать нахождение человека на странице, откуда он пришёл, сколько проводил на сайте и при закрытие вкладки(браузера) или при переходе на другую страницу. В последствие должен уходить json по api. 
p.s. api пока не готово, в режиме отладки записываем json в локальное хранилище браузера

1.1 Создать файл трекинга в src и ипортировать его в teorikaModule.js
1.2 Разработать в новом файле трекинга функционал, который вступит в работу как только скипт прогрузился:
- Отследить на какой странице находится человек сейчас
- Отследить с какой странице перешёл человек
- Расчитать сколько времени провёл человек на странице в секундах
1.3 При закрытие вкладки, закрытие браузера или переходе на другую страницу необходимо данные из пункта 1.2 в json формате сохранить в локальном хранилище
